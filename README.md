# Legal Documents

各アプリの利用規約とプライバシーポリシーを管理するリポジトリです。

## ディレクトリ構造

```
{アプリ名}/
├── terms-of-service.md  # 利用規約
└── privacy-policy.md    # プライバシーポリシー
```

## 新しいアプリを追加する場合

1. `template/` ディレクトリのファイルをコピー
2. `{アプリ名}/` ディレクトリを作成
3. 各ファイル内の `[アプリ名]`、`[会社名]`、`[メールアドレス]` を実際の内容に置き換える

## アプリ一覧

| ディレクトリ | アプリ名 |
|---|---|
| `my-app/` | My App |
